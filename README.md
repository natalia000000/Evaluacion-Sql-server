-Gráfico de barras: Ventas por título y plataforma.
Este gráfico muestra la cantidad de unidades vendidas para cada combinación de videojuego y plataforma. Permite visualizar qué títulos han tenido mayor éxito en cada plataforma.

-Gráfico de torta: Nivel de ventas
Este gráfico clasifica cada venta individual según la cantidad de unidades vendidas. Las categorías son:

Alta: 7 o más unidades

Media: entre 3 y 6 unidades

Baja: menos de 3 unidades

En el gráfico se muestran las sumas totales de las cantidades vendidas en cada una de estas clasificaciones.
